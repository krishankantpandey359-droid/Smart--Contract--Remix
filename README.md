# Smart Contract Remix
 
A collection of Solidity smart contracts developed and tested using Remix IDE.
 
## Technologies Used
 
- Solidity
- Remix IDE
- Ethereum Smart Contracts
- GitHub
 
## Smart Contracts Included
 
- **CryptoLocking.sol** – Time-based Ether locking and withdrawal functionality.
- **MultiSend.sol** – Allows sending Ether to multiple addresses.
- **PollingSystem.sol** – A simple blockchain-based polling system.
- **SimpleStorage.sol** – Demonstrates basic data storage using Solidity.
 
## Features
 
- Solidity-based smart contracts
- Tested using Remix IDE
- Blockchain-based functionality
- Multiple smart contract examples
- Demonstrates basic Ethereum smart contract concepts
 
## How to Run
 
1. Open the project in Remix IDE.
2. Select the required `.sol` contract.
3. Compile the contract using the Solidity Compiler.
4. Deploy the contract using Remix's deployment environment.
5. Interact with the deployed contract functions.
 
## Learning Outcomes
 
This project helped me understand Solidity fundamentals, smart contract development, compilation, deployment, and interaction with blockchain-based applications.
